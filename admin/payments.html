Stripe Setup Instructions

To enable live payments, complete these one-time steps. This is a static demo — a server-side backend is required to process real transactions.
  1. Create a free account at stripe.com and complete business verification.
  2. In the Stripe Dashboard → Developers → API Keys, copy your Publishable Key (starts with pk_live_...).
  3. In Settings → Connect, create a Connect application and copy the Client ID (starts with ca_...).
  4. Replace ca_xxx in js/stripe-connect.js and in the connectStripe() function of this page with your actual Client ID.
  5. Set up webhook endpoints in the Stripe Dashboard to handle payment events (payment_intent.succeeded, checkout.session.completed).
  6. Update your bank account details in Stripe Dashboard → Settings → Bank Accounts to receive payouts.
